# compatibility-benchmark

Empirical runtime probe data and analysis artifacts used to validate
PyRift's rules against *observed* CPython behaviour rather than static claims.

## Runtime probes (`runtime-<version>.json`)

Generated by `cpython_runtime_probe.py`. One file per CPython version:

```text
runtime-3.10.json  runtime-3.11.json  runtime-3.12.json
runtime-3.13.json  runtime-3.14.json  runtime-3.15.json
```

Each file records empirically observed results for a set of behaviour
differences:

| probe_key | Rule | What it measures |
|---|---|---|
| `multiprocessing_start_method` | CPY023 | default multiprocessing start method |
| `locale_resetlocale` | CPY027 | `locale.resetlocale()` availability |
| `datetime_utcnow` | CPY036 | `datetime.datetime.utcnow()` deprecation warning |
| `purepath_is_reserved` | CPY050 | `PurePath.is_reserved()` deprecation |
| `pickle_default_protocol` | CPY057 | `pickle.DEFAULT_PROTOCOL` |
| `locals_mutation` | CPY029 | `locals()` mutation no-op behaviour |
| `bool_inversion` | CPY022 | bitwise inversion on bool warning (3.12+) |
| `asyncio_get_event_loop` | CPY038 | `get_event_loop()` warning/raise (3.12+) |

Consumed by `benchmark/runtime_harness.py`, which cross-checks these
observations against each rule's declared affected versions.

## Other artifacts

- `cpython_cases.py` — version-conditional behaviour test cases.
- `cp_python_compatibility_matrix.json` — historical finding matrix.
- Various `*findings.json` / `*details.json` — archived CPython/PyPy scan
  comparisons from earlier compatibility probes.

> These are **generated / historical** artifacts, not source. They are
> excluded from the shipped wheel and ignored by the root scan.
