## [0.8.0] — 2026-08-26

### Added
- `CPY046` — open() without encoding= (platform-dependent before 3.15)
- `CPY047` — collections.abc.ByteString removed in Python 3.15
- `CPY048` — concurrent.interpreters requires Python 3.14+
- `CPY049` — compression.zstd requires Python 3.14+
- `CPY050` — PurePath.is_reserved() deprecated in 3.13, removed in 3.15
- `CPY051` — Global mutable state unsafe in free-threaded Python 3.13+
- `CPY052` — threading.local() atomicity in free-threaded 3.13+
- `CPY053` — typing.get_overloads() requires Python 3.11+
- `CPY054` — int() no longer delegates to __trunc__() in Python 3.14
- `CPY055` — NotImplemented in boolean context raises TypeError in 3.14
- `CPY057` — pickle default protocol changed to 5 in Python 3.14
- `CPY062` — string.templatelib requires Python 3.14+
- `CPY063` — annotationlib requires Python 3.14+
- `PPY046` — __debug__ constant behaviour differs with -O on PyPy
- `PPY047` — ctypes.util.find_library() unreliable on PyPy
- `pyrift.analysis` — shared AST utilities (imports, calls, scope)
- Version-guard awareness — imports inside `if sys.version_info >=` not flagged
- Dynamic import detection — `importlib.import_module()` and `__import__()`
- Golden benchmark suite — 81/81 cases, CI precision gate
- Self-scan quality gate — 120 files, 0 findings
- Corpus benchmark — 7 real packages validated
- Runtime differential harness — 5 rules verified across 6 Python versions
- Release gate — all checks must pass before PyPI publish
- Confidence field — HIGH/MEDIUM/LOW independent of severity
- `by_statement()` dedup — multi-name from imports produce one finding
- BOM-safe scanning — utf-8-sig encoding, 0 parse errors on BOM files
- ASCII-safe output — no Windows console encoding crashes

### Fixed
- CPY057: protocol=None now correctly flagged (same as no protocol)
- CPY057: pickle.Pickler() now detected
- PPY009: no longer flags id() used as dict key or local dedup variable
- PPY043: removed from ALL_RULES (not actionable)
- CPY041: no longer flags bare `a | b` (ambiguous — could be bitflags)
- CPY023: no false positive when set_start_method already called
- CPY029: no false positive on print(locals())
- PPY016: no false positive on self.__dict__ inside class methods
- PPY024: only flags when timeit result stored
- PPY034: only flags when hash result stored or compared
- PPY038: only flags when decimal context modified
- cpy050 filename typo fixed (purepatth → purepath)
- 15 BOM-corrupted files stripped
- Duplicate findings from multi-name from imports fixed

### Changed
- 519 tests total
- 22 rules migrated to shared pyrift.analysis utilities
- docs/rules.md auto-generated (104/104 rules documented)
- README stats auto-generated by scripts/generate_docs.py
